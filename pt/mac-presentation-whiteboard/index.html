Como usar um quadro branco para apresentações no Mac

Precisa de espaço para um desenho durante uma apresentação no Mac? Um quadro branco com várias páginas permite desenvolver a explicação sem encher uma única tela.

Resposta curtaAbra o quadro branco do TeacherPalette e separe exemplos e comparações em páginas diferentes. Salve a sessão para continuar das mesmas páginas na próxima vez.

Organize a apresentação em várias páginas

Uma página pode receber um esboço, um exemplo, uma pergunta ou uma conclusão. Alterne entre páginas para mostrar como as partes se conectam.

Mantenha todo o fio do raciocínio

Salve a sessão ao terminar. Na próxima vez, você poderá ampliar as páginas existentes em vez de começar com uma tela vazia.
