Whiteboard and PDFs

Don’t throw away a good explanation.

Some of the best teaching happens in the margin: the arrow you add to a diagram, the quick example beside a definition, the question that changes the order of the lesson. Whiteboard is a way to keep that useful work.

Start with the material you already have

Load a PDF directly onto the canvas when the conversation begins with a worksheet, a slide export or a handout. You can annotate on top instead of rebuilding the document from scratch, and your writing stays connected to the original context.

Let each page carry one thought

When an explanation starts to branch, add a page rather than compressing everything into one crowded canvas. One page for the concept, one for the worked example, one for the question from the room: this makes the session easier to revisit and easier to share.

Use separate pages to keep an evolving explanation readable.

Save it while it is still useful

Open a past session from Session History when a lesson or demo deserves another run. When you are done, export or print the annotated PDF; the original material and your handwriting stay together, ready to hand out.
