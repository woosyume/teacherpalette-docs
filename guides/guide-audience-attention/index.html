Audience attention

Give people one place to look.

When someone says “over here” during a screen share, half the room scans the wrong half of the screen. Attention tools are not decoration; they are a quiet way to remove that little moment of friction.

Use one cue for one job

Spotlight sets the stage

Use it when a region—not a single pixel—is the subject. Dim everything around the cursor, then pause for a moment. The pause matters: it lets the eye arrive before you start explaining.

Laser shows a path

Laser is best for movement: from a menu to a setting, from an input to an output, or through a diagram. If it stays on too long, it becomes visual noise. I use it like a spoken gesture, then let it disappear.

Magnifier makes the small stuff humane

Use Detail mode for a quick check and Reading mode when people need time with small text. TeacherPalette remembers a zoom level for each, so the switch does not become a mid-presentation adjustment ritual.

Make clicks visible when the action matters

A Click Highlight ripple is particularly helpful in software demos, where a quiet click can be the entire transition. Trigger it at the moment you act—not every time the pointer moves—and it feels like a deliberate signal rather than an effect.

Detail and Reading modes make it easier to show both tiny UI details and longer passages.
