Cómo escribir y dibujar en la pantalla del Mac

¿Quieres escribir o dibujar en la pantalla del Mac mientras explicas una diapositiva o una aplicación? Las anotaciones en pantalla permiten señalar lo importante sin cambiar de ventana.

Respuesta breveTeacherPalette es un kit de presentación nativo para Mac. Usa lápiz, resaltador, flechas, texto y formas directamente sobre la aplicación que estás mostrando.

Escribe sobre la aplicación que estás mostrando

Abre la aplicación y rodea el dato importante o conecta dos elementos con una flecha. Deja solo las marcas necesarias para explicar el paso actual.

Mantén las anotaciones legibles

Resalta una frase sin taparla y delimita una zona con un rectángulo. Borra las marcas antes de pasar al siguiente punto para que la pantalla siga siendo clara.
