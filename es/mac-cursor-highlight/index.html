Cómo resaltar el cursor del ratón en Mac

¿Tu público pierde de vista el puntero al compartir pantalla en Mac? Resaltar el cursor ayuda a localizar el botón o menú que estás explicando.

Respuesta breveTeacherPalette permite resaltar el cursor, señalar con un puntero láser o iluminar una zona con el foco. Elige la señal que mejor muestre la acción.

Elige entre cursor resaltado, láser y foco

Resalta el cursor para señalar un botón. Usa el láser para recorrer un menú o un diagrama y el foco cuando importe una zona más amplia.

Comprueba la visibilidad antes de presentar

Prueba el efecto en la aplicación que vas a mostrar. Utiliza una señal discreta y actívala cuando el público necesite seguir una acción.
