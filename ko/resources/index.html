수업과 실시간 발표에서 TeacherPalette의 도구를 활용하는 방법을 알아보세요.

사용 가이드

맥 화면에 주석을 달고 필기하는 방법

맥과 맥북 화면에 직접 주석을 달고 필기하는 방법입니다. TeacherPalette의 펜, 형광펜, 화살표, 텍스트로 앱을 전환하지 않고 발표 내용을 설명하세요.

글 읽기 → 사용 가이드

맥에서 마우스 커서를 강조하는 방법

맥 화면 공유 중 마우스 커서를 잘 보이게 만드는 방법입니다. TeacherPalette의 커서 강조, 레이저 포인터, 스포트라이트로 청중의 시선을 안내하세요.

글 읽기 → 사용 가이드

맥 프레젠테이션에서 화이트보드 사용하는 방법

TeacherPalette의 맥 발표용 화이트보드에서 여러 페이지로 예시와 그림을 정리하세요. 저장한 화이트보드를 다시 열어 다음 수업이나 회의에서 이어 쓸 수 있습니다.

글 읽기 → 사용 가이드

맥에서 PDF에 필기하며 발표하는 방법

맥에서 PDF를 보여주며 필기하고 강조하는 방법입니다. TeacherPalette 화이트보드로 PDF를 불러와 페이지별로 주석을 달고, 발표 후 내보내거나 인쇄하세요.

글 읽기 → 사용 가이드

맥에서 발표와 소프트웨어 데모에 쓰는 도구

맥 소프트웨어 데모와 발표에 필요한 도구를 준비하세요. TeacherPalette의 커서 강조, 돋보기, 전역 단축키, 화이트보드로 조작과 설명을 명확하게 전달합니다.
